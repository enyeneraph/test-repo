# test-repo
To clone a repo

1. `git clone <url>`
   

2. To stage changes  
   `git add <file>`

3. To revert changes you added. 
   `git restore --staged <file>`

4. creating a branch. 
    `git checkout -b <newbranchname>` 

5. committing staged changes  
    `git commit -m <commit message>`

6. pushing changes. 
   `git push origin`

7. push changes to a new branch. 
   `git push --set-upstream origin test-dev`
